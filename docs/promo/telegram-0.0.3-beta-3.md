**w0y 0.0.3 beta-3 — новый плеер и обновления прямо из приложения**

Что нового:

— **Новый плеер.** «Обложка в рамке» (по умолчанию) и «Постер»: размытая обложка на весь экран, контурные кнопки, всё без прокрутки. Сворачиваешь — обложка перелетает в мини-плеер. Смахивание вниз закрывает плеер везде.
— **Имя исполнителя — ссылка** на артиста, название — на альбом.
— **Быстрый выбор** на главной: подборка из того, что ты недавно слушал, колонками по четыре.
— **Итоги года** в статистике: минуты, исполнитель года, топ-5, твой ритм и карточка для сторис. Считается на телефоне.
— **Обновления из GitHub**, как в Obtainium: при запуске «Обновить / Позже», после обновления — окно «Что нового».
— Новые обои-контуры, текст песни выезжает сверху, ошибки поиска видны (есть Copy debug info), защита от случайного удаления.

Ничего не уходит с телефона, кроме запроса к странице релизов. Свежая версия ставится поверх прежней.
