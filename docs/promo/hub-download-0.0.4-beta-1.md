# w0y — теперь и на компьютере

**Windows 10/11 · Linux · Android 8+**

Один и тот же клиент YouTube Music: быстро включает, много настраивается, без рекламы и без телеметрии.

| Платформа | Файл |
|---|---|
| Windows (установщик, без прав администратора) | `w0y-windows-x64-setup.exe` |
| Windows (portable) | `w0y-windows-x64-portable.zip` |
| Linux | `w0y-linux-x86_64.AppImage`, `w0y-linux-x86_64.tar.gz` |
| Android | `TexFi-w0y-android.apk` |

Контрольные суммы: `SHA256SUMS.txt` (Android) и `SHA256SUMS-desktop.txt` (компьютер).

**Windows:** установщик без платной подписи, поэтому SmartScreen может показать предупреждение. Сверь сумму,
затем «Подробнее → Выполнить в любом случае». Подробности: `docs/WINDOWS_INSTALL.md`.

**Что уходит из приложения:** YouTube (поиск, музыка, вход) и GitHub (проверка обновлений, выключается).
Остальное остаётся у тебя на устройстве.

# w0y — now on the computer too

**Windows 10/11 · Linux · Android 8+** — one client for YouTube Music: quick to start, very adjustable,
no ads, no telemetry. Download links and checksums as above. On Windows the installer is unsigned, so
SmartScreen may warn: check the hash, then "More info → Run anyway".
